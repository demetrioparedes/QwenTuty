# MISSION SPECIFICATIONS
## ANTIGRAVITY: Robot Boss Academy

### LEVEL 1: NOVICE (El Despegue)

**Mission 1: "Hello World"**
- **Objective:** Install Antigravity simulator and sign in.
- **Action:** Click "Install" button in the simulated store, then "Open".
- **Win Condition:** Dashboard loads.
- **Badge:** 🚀 Pilot

**Mission 2: "Command Center"**
- **Objective:** Create first workspace.
- **Action:** Click "New Workspace", enter a name (e.g., "MarsBase").
- **Win Condition:** Workspace created.
- **Badge:** 📂 Organizer

**Mission 3: "Safe Configuration"**
- **Objective:** Set agent mode to "Agent-assisted".
- **Action:** Go to Settings > Agent Mode > Select "Assisted".
- **Win Condition:** Setting saved.
- **Badge:** 🛡️ Guardian

### LEVEL 2: EXPLORER (Usando Herramientas)

**Mission 4: "Ghost Browser"**
- **Objective:** Command robot to visit a URL.
- **Action:** Type `visit google.com` in terminal.
- **Win Condition:** Browser preview shows the page.
- **Badge:** 🌐 Navigator

**Mission 5: "Proof Hunter"**
- **Objective:** Find and open a Screenshot Artifact.
- **Action:** Locate the "Artifacts" tab, click the screenshot icon.
- **Win Condition:** Image modal opens.
- **Badge:** 📸 Detective

**Mission 6: "Inbox Master"**
- **Objective:** Navigate chat history.
- **Action:** Click "Back to Inbox", select a different thread.
- **Win Condition:** Successfully switch contexts.
- **Badge:** 📥 Messenger

### LEVEL 3: BUILDER (Creador de Apps)

**Mission 7: "Action Plan"**
- **Objective:** Request a Todo List and comment.
- **Action:** Type request, then click on the generated plan text to add a comment "Change color".
- **Win Condition:** Comment attached.
- **Badge:** 📝 Architect

**Mission 8: "Fast Mode"**
- **Objective:** Rename a variable using Fast Mode.
- **Action:** Toggle "Fast Mode", select text in editor, type new name.
- **Win Condition:** Code updates.
- **Badge:** ⚡ Speedster

**Mission 9: "Code Wizard"**
- **Objective:** Use AI Code Gen (Cmd+I).
- **Action:** Press Cmd+I (or button), type "Create math function".
- **Win Condition:** Code inserted.
- **Badge:** 🪄 Sorcerer

### LEVEL 4: EXPERT (Jefe de Agentes)

**Mission 10: "Golden Rules"**
- **Objective:** Create a custom rule.
- **Action:** Open `.cursorrules` (simulated), add "Always speak Spanish".
- **Win Condition:** Rule file saved.
- **Badge:** 📜 Legislator

**Mission 11: "Multitasking"**
- **Objective:** Run 2 missions.
- **Action:** Open new tab, start second agent task.
- **Win Condition:** Two progress bars active.
- **Badge:** 🧠 Multiprocessor

**Mission 12: "The Grand Combo"**
- **Objective:** Create automated tests.
- **Action:** Drag "Test" block to workflow editor.
- **Win Condition:** Workflow executes green.
- **Badge:** 👑 Grand Master
