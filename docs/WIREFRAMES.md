# UI/UX WIREFRAMES
## ANTIGRAVITY: Robot Boss Academy

### 1. Main Menu (Spaceship Hub)
**Layout:**
- **Background:** View of space from the cockpit.
- **Center:** "Play" button (pulsing).
- **Top Right:** Profile summary (Name, Level, XP).
- **Bottom:** Quick links to "Settings", "Badges", "Course Videos".
- **Visuals:** A cute robot floating nearby.

### 2. Mission Select (Star Map)
**Layout:**
- **Background:** A star map connecting different planets/nodes.
- **Nodes:**
    - 4 Major clusters (Level 1, 2, 3, 4).
    - Each cluster has 3 mission nodes.
    - Locked nodes are greyed out.
    - Completed nodes have a gold checkmark.
- **Hover:** Hovering a node shows "Mission Title" and "Rewards".

### 3. Interactive Workspace (The Game)
**Layout:** Split Screen (60/40)
- **Top Header:** Mission Objective (e.g., "Objective: Rename Variable").
- **Left Panel (Terminal/Editor):**
    - Code Editor area (Monaco).
    - Terminal input at the bottom.
    - "Run/Execute" button.
    - "Agent" avatar providing hints in a speech bubble.
- **Right Panel (Preview/Browser):**
    - Simulates a web browser or mobile preview.
    - "Artifacts" tab to view screenshots.
- **Bottom Bar:**
    - Progress bar for the current mission step.
    - "Hint" button (glowing if stuck).

### 4. Badge Collection Screen
**Layout:** Grid View
- **Title:** "Hall of Fame".
- **Grid:** 3x4 grid displaying the 12 badges.
- **State:**
    - Unlocked: Full color, shiny effect.
    - Locked: Silhouette with "???" text.
- **Detail View:** Clicking a badge shows "Date Earned" and "Description".

### 5. Certification Screen
**Layout:** Document Style
- **Frame:** Gold border.
- **Content:**
    - "Certificate of Completion"
    - "Awarded to [Player Name]"
    - "For mastering Antigravity Levels 1-4"
    - Date and Unique ID.
- **Actions:** "Download PDF", "Share on Twitter".
