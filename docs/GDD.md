# GAME DESIGN DOCUMENT
## ANTIGRAVITY: Robot Boss Academy

### 1. Executive Summary
**Project Name:** ANTIGRAVITY: Robot Boss Academy
**Target Audience:** 12-year-old beginners in programming (Spanish speakers).
**Platform:** Web-based (HTML5 + React + Phaser 3).
**Core Concept:** An interactive educational game where players take the role of a "Robot Boss" in a space station. By commanding AI robots, they learn to use the Antigravity platform.
**Objective:** Complete 12 gamified missions to earn the "Certified Junior Robot Boss" title.

### 2. Narrative Setting
- **Setting:** The "Antigravity Spaceship", a futuristic vessel exploring the code cosmos.
- **Player Role:** Cadet / Junior Commander.
- **Companions:** Cute AI robots that execute commands.
- **Theme:** "Boss of Robots" – emphasizing that the player directs the AI, rather than writing every line of code manually.

### 3. Core Gameplay Loop
1.  **Briefing:** Receive a mission from the Command Center (e.g., "We need to scan this planet using the browser agent").
2.  **Action:** Enter the "Workspace" (Game View).
3.  **Command:** Use the simulated terminal or drag-and-drop interface to issue commands to the robot.
4.  **Feedback:** The robot performs the action (animated) and provides real-time logs/output.
5.  **Result:** Success (Badge awarded) or Retry (Hint provided).
6.  **Progression:** Unlock next mission and customize the ship/robot.

### 4. Progression System
- **Levels:** 4 Levels (Novice, Explorer, Builder, Expert).
- **Missions:** 12 Total (3 per level).
- **XP System:**
    - 50-200 XP per mission.
    - 1200 XP required for certification.
- **Badges:** 12 Unique collectible badges.

### 5. Engagement Hooks
- **Instant Gratification:** Every correct command triggers a satisfying animation/sound.
- **Visual Progression:** The spaceship hub becomes more populated/upgraded as missions are completed.
- **Certification:** A downloadable certificate upon completing the game.

### 6. Visual Style
- **Palette:** Deep Space Blue (#1A1D3A), Electric Purple (#7B68EE), Neon Cyan (#00D4FF), Gold Star (#FFD700).
- **Art Style:** Flat design, futuristic, neon accents.
- **UI:** Rounded corners, large interactive buttons, terminal-aesthetic for the code editor but simplified.

### 7. Accessibility
- **Language:** Spanish (Latin America).
- **Controls:** Keyboard + Mouse.
- **Support:** Screen reader friendly (WCAG AA).

### 8. Detailed Mission List (Summary)
*See MISSION_SPECS.md for full details.*

- **Level 1 (Novice):** Hello World, Command Center, Safe Configuration.
- **Level 2 (Explorer):** Ghost Browser, Proof Hunter, Inbox Master.
- **Level 3 (Builder):** Action Plan, Fast Mode, Code Wizard.
- **Level 4 (Expert):** Golden Rules, Multitasking, The Grand Combo.
